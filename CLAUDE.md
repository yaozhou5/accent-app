## Working rules

- Never run `db push`, migrations, or SQL against production without asking first.
- Work on a feature branch off master, deploy previews, never merge to master without my go-ahead.
- Plan first and wait for approval on anything non-trivial.
- Privacy: analytics carry counts only, never content. If a change would affect what `/privacy` says, say so and propose the new wording.
